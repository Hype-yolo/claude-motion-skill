## 使用边界

- Three.js 标记的案例需要单独安装并满足原例导入路径；本 Skill 不自动补齐 GLTF、HDR、纹理或字体。
- 字体回退影响排版与原貌；需要精确字形时自行提供有授权的本地字体。
- 木刻预览采用原例的测试入口；完整原片初始化还需要未收录纹理。可调用绘图引擎改编，不宣称完整原片可离线直接播放。
- 导出器阻断外部资源请求，作品需将所需资源放入作品目录。
- 来源署名保留作者声明；没有 API 日志证明每份源码由特定模型生成。
