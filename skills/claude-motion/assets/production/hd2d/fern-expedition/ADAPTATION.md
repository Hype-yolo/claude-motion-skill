# 林间的发现

18 秒，1280×720，24fps。有参考的新题材开发片，不是闭卷或有无 Skill 盲测。

来源：https://github.com/lemomo-ai/lemo-opuscar，固定提交 c4bc370eb15d36c88e074fdba1b0248b62a8e419。文件哈希见 ENGINE-INPUT.json。上游模型归属为作者声明，没有独立核验 API 日志。

实际沿用：PX、图集、受光 billboard、世界材质和景深。

本轮新做：探险者图案、蕨叶、七瓣花模型、花瓣铰接和新镜头。

边界：人物与植物多为受光平面；花瓣为三维，不是完整植物生理模拟。

音频：本轮编写的确定性合成配乐与事件提示音，无外部音轨、无配音、无额外中文字幕。存在音轨和声级检查不代表真人听感验收。许可证在 licenses/。

检查：代表帧与动作检查记录于本轮 QA.md；最终导出、解码、乱序寻帧由 film-render-report.json 记录。此文件不是测试通过声明，实际状态以报告为准。原试点的用户认可不自动适用于这支新片。
