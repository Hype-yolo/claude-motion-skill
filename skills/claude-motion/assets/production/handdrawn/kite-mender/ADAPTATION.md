# 借一点风

18 秒，1280×720，24fps。有参考的新题材开发片，不是闭卷或有无 Skill 盲测。

来源：https://github.com/JohnHeibel/ClaudeAnimationBase，固定提交 0ac8bf2b31942376cb6b8c4074715595d512acd2。文件哈希见 ENGINE-INPUT.json。上游模型归属为作者声明，没有独立核验 API 日志。

实际沿用：ClaudeAnimationBase 原 Clawd 角色，项目改编的颜料、墨线、表情、多视图和动作引擎。

本轮新做：风筝、尾带、补丁、道具位置与故事表演。

边界：角色造型明确复用；没有新增通用人体模型，也没有训练模型权重。

音频：本轮编写的确定性合成配乐与事件提示音，无外部音轨、无配音、无额外中文字幕。存在音轨和声级检查不代表真人听感验收。许可证在 licenses/。

检查：代表帧与动作检查记录于本轮 QA.md；最终导出、解码、乱序寻帧由 film-render-report.json 记录。此文件不是测试通过声明，实际状态以报告为准。原试点的用户认可不自动适用于这支新片。
