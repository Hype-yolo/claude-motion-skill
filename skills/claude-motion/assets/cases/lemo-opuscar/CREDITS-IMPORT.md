43 style source directories plus their shared core are preserved. IMPORT.json records each original copied file SHA-256. Original style implementation files were not rewritten. Their STYLE.md, DEMO.md, music credits, OFL notices and vendor licenses remain at upstream relative paths. The repo-level README and package metadata remain unchanged as evidence, not as a promise that all their external dependencies are included.

Claude Opus 5.5 attribution is the author's claim. It has not been independently verified from model API logs. Local round-03 experiments are not included or labeled as Claude cases.

## Excluded / unavailable assets
No external media were fetched. Binary audio, video, images, webfont files, HDR textures and GLTF models are not imported. The checked-out source already omits most of these. Do not treat source MIT as a blanket license for third-party assets. Text metadata, source audio generators and original credits are retained; they are not a bundled soundtrack. The scraped external music-library HTML was excluded as third-party content; its removal is recorded in IMPORT.json.

## Preview boundary
Previews execute original code in local Chromium. A browser adapter catches failed document.fonts.load calls so native fallback fonts can render. Geometry, drawing functions and source pixels are not replaced. No remote request is allowed during capture. Two sampled timestamps are checked for differing screenshots; this is not a complete-film or audio check. Every case records observed missing URLs and errors in the catalog. The woodcut preview uses the original ?test=village source entry, since full film init needs an omitted walnut texture. Missing cases remain source-only, with no fabricated poster.

Use case-catalog.json for actual runtime status. Source-index.json covers 81 researched repositories but only one of those is imported here; the 43 cases are not 43 independent repositories.
