# 风留下的笔迹 · 扩充后 Skill

提示词：一台海边气象站里的老式自记风速仪，风起时风杯转动，齿轮带动记录笔在纸卷上画出曲线，阵风过去后线条恢复平稳。

## 实际使用

- wheresryan22/anatomy @ 689dcf966e63d92be10a5d593c6e19e10acd4422，MIT；vendor/iso-kit.mjs 原样保留。
- mechanisms.js 的 solid 直接绘制上游 extrude 输出的 fill、top、shades、outline、crease、bevel 路径；gear 使用同一拉伸实现；scene.js 实际调用 cylinder、slabOf、planOutline、knurl、segment、iso、topMatrix 等。不是仅读源码后另写替代渲染器。
- 本地新写齿轮轮廓、配色与 Canvas 桥接，不是制造级渐开线齿轮，不作真实仪器工程准确性声明。

## 新写内容

全新风速仪主体、三风杯、两级反向齿轮、离心调节架、固定笔尖和转动纸鼓；新建气象站窗口、海面、桌面。风速时间函数驱动杯转速、调节架与笔尖高度，纸鼓按独立缓慢角速度移动，已写曲线随纸鼓转动。静态背景粒子固定随机种子；动作按绝对时间求值。

本片为简化机制展示。调节架与笔杆是运动学编排，不是力学求解；风杯形态、反向传动、笔纸接触和曲线恢复平稳在抽帧中核对。
