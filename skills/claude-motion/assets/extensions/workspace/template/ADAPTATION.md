## Actual retained implementation
Original props.glb geometry with vertex-color five-class materials, including desk/chair/lamp/mug/pen holder/notebook/laptop/bookshelf/plant/clock; original woodTexture seeded plank/grain and withLampLight/setLampPools shader patch actually used on paper. Original Blender generators are included.

## New subject, event and camera
New shared-studio arrangement; original office objects are reused rather than claimed new. New mechanical two-link drafting arm, geometric pen/IK placement, spiral path and lamp/camera timeline.

## Asset and licensing boundary
MIT code and self-authored procedural prop assets, documented in assets/blender/README.md as generated by bundled Python scripts. No sounds (CC0), fonts (OFL), character avatar or live session/server features used.

## Runtime boundary
Three 0.170.0 bundled. Native scene only; office backend, live Claude sessions, navigation and character life are not imported.

## Editable files and rendering
Edit scene.source.js, then npm install and npm run build; the ready scene.js bundle needs no network or npm to preview.
Run a local static server in this folder. index.html renders the source at time 0; call render(t) to seek. preview.html plays film.mp4 after export.

Render: node <skill>/scripts/render.mjs --root <out> --page index.html --out <out>/film.mp4 --fps 24 --gpu metal

Target: 18 seconds, 1280x720, 24 fps, 432 frames, silent. Initial representative frames inspected before first full export. First complete export will be frozen under first-export/ and hashed; later revisions, if any, must be separate. No external generation service or image generation used.
