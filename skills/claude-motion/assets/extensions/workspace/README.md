# 程序生成办公室道具与材质

创建：`node skills/claude-motion/assets/extensions/workspace/create.mjs --out <新目录>`。输出必须不存在。

实际上游：https://github.com/Edd-io/Workspace/tree/e50a203051a173f5191977d13e2259d1952de676，许可证原文和 SOURCE.json 中的 SHA-256 随工程复制。

实际保留：Original props.glb geometry with vertex-color five-class materials, including desk/chair/lamp/mug/pen holder/notebook/laptop/bookshelf/plant/clock; original woodTexture seeded plank/grain and withLampLight/setLampPools shader patch actually used on paper. Original Blender generators are included.

新题材：New shared-studio arrangement; original office objects are reused rather than claimed new. New mechanical two-link drafting arm, geometric pen/IK placement, spiral path and lamp/camera timeline.

边界：Three 0.170.0 bundled. Native scene only; office backend, live Claude sessions, navigation and character life are not imported.

资产许可：MIT code and self-authored procedural prop assets, documented in assets/blender/README.md as generated by bundled Python scripts. No sounds (CC0), fonts (OFL), character avatar or live session/server features used.

创建的是可编辑的新故事示例，不能复制样片后只改标题称作另一支新片。工程不调用外部服务或生图。静态预览使用本地服务器；preview.html 在导出后播放 MP4。

导出：`node <skill>/scripts/render.mjs --root <out> --page index.html --out <out>/film.mp4 --fps 24 --gpu metal`。
