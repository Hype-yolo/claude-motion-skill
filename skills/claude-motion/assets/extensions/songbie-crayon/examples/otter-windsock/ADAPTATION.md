# Editable Songbie crayon starter

This is the source of the new otter/windsock example, adapted from Johnny Wang's MIT songbie renderer at commit 97225eb54a351c9938ad896e04bef7a7020393fb. The original story is snowman/piano/cat. The original story is not contained in this scene.

Retained: crayon, PRESS, broken contours, paper tooth, three-frame BOIL, pinhole projection, box face culling, depth-sort criterion. Changed: arbitrary-sized Canvas factory and wider paper-grid allocation. New authored story: otter repair, needle/thread, developing stitches, wind return, sleeve lift, anemometer, same-character river reflection.

Scene contract: 18 seconds, 1280×720, render(ctx,t), silent, no subtitles. Copyright and provenance: LICENSE.songbie and SOURCE.json.

This copied starter contains editable sources, not a pre-exported film. Run npm install, npx playwright install chromium, then npm run render. Inspect the output and its newly generated report before claiming verification for this project. The original validated adaptation is separately stored in learning/ab-test-13/skill/otter; its verification is not inherited by newly edited copies.
