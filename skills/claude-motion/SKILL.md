# Claude Motion

默认采用**案例辅助创作**：先找到适合题目的真实实现，再改编。只读文字方法后从零画几何图形，不等于使用了这个案例库。名称表示用户希望接近的视觉方向，不保证模型身份或审美效果。

分别检查风格辨识度与画面完成度；能认出使用了案例不等于作品更好。默认先用案例源码，不把新增生图设为必需步骤；需要明确造型或用户要求时再加图。现有定性比较支持这一默认路线，但尚未证明跨题材稳定提升，也不意味着所有题目都应套同一种画风。

v0.1.0-beta.1 收录 47 套源码案例；36 套有原例抽帧，11 套预览不可用。抽帧多数使用字体回退，不等于完整影片或音频验证。安装、各案例状态及依赖见 [安装与验证](references/installation.md) 和 [案例状态表](references/case-status.md)。

## 选择实际案例

运行 `node <skill>/scripts/route.mjs --query "<用户题目>" --limit 5`。结果来自 [案例目录](references/case-catalog.json)，包括来源、适用场景、源码路径、素材缺口与预览状态。题目未指定风格时，结合角色动作、空间关系、叙事跨度和材质选择，不只匹配题目中的一个名词。关键词排序是查找帮助，不替代视觉判断；可以改写为视觉需求再检索，或用 `--list` 查看目录。

读候选的 styleGuide、demoGuide 和相关绘图模块，查看可用预览。选一个主案例，确有必要时补充第二个。先运行最关键的绘图机制，确认它在当前环境下真实可见。未运行的样片不能声称已复现；缺少字体、图片、三维依赖的条目要先补齐合法依赖或选别的案例。[来源索引](references/source-index.json) 含更广的研究清单，**索引条数不等于可调用案例数**。

用 `node <skill>/scripts/prepare-case.mjs --case <id> --out <作品目录>` 复制选定案例及公共代码，保留许可证和来源清单。命令支持逗号分隔的多个 ID。它复制源码，不自动安装依赖或补齐缺失素材。完整原片只作为参考；不要把原片换标题或直接截取其片段当成新创作。

## 保留什么，重新写什么

保留产生视觉特征的**实际实现**：造型路径、排线或笔触、印刷合成、角色关节、遮挡与透视、运动节奏等。可原样调用、参数化或在署名下改编。不要只提炼颜色、加一层噪点，就丢掉原本让画面成立的结构。

尤其检查材质合成器、轮廓绘制和角色动作是否真正被调用。同样写着“木刻”，保留原版印刷合成与只借排线会得到不同结果；参考图的配色不能自动成为删掉原机制的理由。制作说明写清实际保留、替换和舍弃了什么。

根据新题目重写物件、人物关系、故事事件、构图和镜头。复用角色或场景资产时在制作说明里明确指出。跨时代或跨场景的题目需要多个可辨认的视觉状态和真实动作，不能只用标签替换表达发展。镜头需留出观看细节和动作结果的时间。

先做一段有代表性的画面和动作，检查主体轮廓、材质层次、景深/遮挡、接触与运动连接；有问题先改到可用，再扩展整片。检查时临时隐藏标题：若标题一去掉就只剩几何示意，继续完善主体绘制。参考作品可以用于正常创作审查，这个模式不是“闭卷”。

`assets/runtime/` 是本项目较轻量的辅助工具，API 见 [runtime.md](references/runtime.md)；它们不是所选案例的替代品。[direction.md](references/direction.md) 是可选构思辅助，不要求把每条规则都套进影片。

## 导出和交付

作品目录提供 `scene.js`，导出 `width`、`height`、`duration` 和 `render(ctx,t)`；可选 `ready`、`audioWav()`。可以使用 Canvas、离屏 WebGL、局部缓存或静态绘画层，不限于几何图形。资源在作品根目录内，按任意时间确定性绘制；具体接口见 runtime.md。

先抽帧检查，再运行 `node <skill>/scripts/render.mjs --root <作品目录> --out <作品目录>/film.mp4 --fps 24`。需要 Node 22+、Playwright Chromium、FFmpeg（含 ffprobe）。在 Skill 目录执行 `npm ci` 和 `npm run setup`；导出器优先使用 Skill 自身安装的 Playwright。依赖解析可通过 `MOTION_PLAYWRIGHT_MODULE` 指向已有 Playwright。无 audioWav 就没有声音；不要把无声片称为有声片，也不因聊天语言擅自添加中文字幕。

交付源码、MP4、可播放的本地预览和简短 `ADAPTATION.md`：列出来源/提交、保留与改写的实现、使用的资产与许可证、实际检查和未解决问题。来源归属是作者声明，不冒充已审计的模型调用。技术通过不等于“已达到 Claude 感”。不自动公开发布。

## 隔离比较

用户要求比较时，先冻结此 Skill，再用全新上下文生成 Skill 版；无 Skill 版只给相同题目、技术规格与中性导出器。两边使用相同模型设置和允许的自查次数，不给无 Skill 版负面风格指令，不泄露另一组画面或用户偏好，不替它故意简化。开发试作和正式结果分开，首次正式结果封存；发现效果不佳如实保留，修订另开版本。

用户明确要求“闭卷/仅方法”时，切换回方法模式并禁用案例源码、预览和资产；不能把案例辅助的收益称为无参考迁移，也不能从单次对照推断普遍提升。
